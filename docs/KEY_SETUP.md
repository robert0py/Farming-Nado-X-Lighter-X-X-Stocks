# Nado через MetaMask, Lighter через Robinhood Wallet

Для баланса достаточно публичного адреса аккаунта. Для торговли нужен отдельный зарегистрированный signer/API private key. Основной ключ кошелька и seed-фраза боту не нужны. API private key вставляйте только в форму приложения, не присылайте в чат или GitHub.

## Lighter · Robinhood Chain · Robinhood Wallet

В боте откройте **Торговля → Настроить ключ Lighter**. По умолчанию выбран **Robinhood Wallet · API-ключ с сайта Lighter**, с инструкцией и переходом на [официальную страницу API Keys](https://robinhoodchain.lighter.xyz/apikeys). На сайте она находится в меню **Tools → API Keys**.

1. Нажмите **Connect Wallet → Robinhood Wallet**. Подтвердите подключение на телефоне. Если появился QR-код, используйте сканер Robinhood Wallet. Сверьте адрес с кошельком аккаунта Robinhood Chain.
2. Нажмите **Generate API Key**. Выберите свободный **API Key Index: 4–156 или 158–254**. Не используйте 0–3 и 157 и не заменяйте занятый ключ. **Maker Only** оставьте выключенным: стратегия использует IOC-ордера.
3. Подтвердите привязку в кошельке и дождитесь успешного результата. Скопируйте **Your Account Index**, **API Key Index** и **Private Key**. Private Key доступен только в окне создания — скопируйте его до закрытия. Публичный ключ и read-only token не подходят.
4. Вставьте публичный адрес кошелька, два индекса и Private Key в форму бота. Индекс аккаунта может подставиться из баланса. Вводите индексы числами, без `#`. Отдельный API private key Lighter — 40 байт / 80 hex-символов, с необязательным `0x`.
5. Нажмите **Сохранить ключ** или Enter, затем **Проверить доступ**. Эта проверка не открывает ордера. Worker хранит ключ зашифрованно.

Если браузер не открылся, нажмите **Скопировать адрес сайта** и откройте его вручную. Если Private Key потерян, создайте новый отдельный ключ в свободном индексе: публичный API не позволяет восстановить секрет. Экспортировать seed-фразу Robinhood Wallet в MetaMask не требуется.

Способ **MetaMask · создать API-ключ в боте** оставлен для аккаунтов MetaMask. Он использует одноразовую страницу бота и отдельную подпись владельца. Robinhood Wallet подключается на официальном сайте Lighter; дополнительная регистрация в Reown / Project ID не требуется.

## Nado · spot xStocks · MetaMask

Выберите **Настроить ключ Nado → MetaMask · создать отдельный signer**. Проверьте адрес и субаккаунт, нажмите **Создать ключ и открыть браузер**. На странице бота подключите MetaMask с этим адресом, затем отдельно подпишите привязку. При необходимости подтвердите сеть Ink. Вернитесь в бот и нажмите **Проверить доступ**.

Signer создаётся в worker. Основной ключ MetaMask не нужен. Если отдельный signer уже зарегистрирован, выберите **Вставить уже привязанный signer → Сохранить ключ**. Новый signer Nado заменяет 1-Click Trading и отменяет resting-ордера; он имеет полные права субаккаунта.

## Множитель поинтов

[Объявление Robinhood](https://robinhood.com/newsroom/robinhood-accelerates-global-expansion-robinhood-chain-mainnet-stock-tokens-agentic-trading/?lang=en) описывает 2× для сделок через Robinhood Wallet и 1× через веб-приложение Lighter, с учётом условий программы. **Подключение Robinhood Wallet и получение API-ключа не подтверждают 2× для сделок бота через API.** Бот не показывает этот множитель как установленный факт; это требует отдельного подтверждения Lighter для API-торговли.

Проверено 09.10.2026: публичная страница `/apikeys`, меню Tools, Robinhood Wallet в окне входа и опубликованный интерфейс создания ключа с тремя полями копирования. Пользовательские ключи и подписи при проверке не создавались.

Источники: [API Keys Lighter](https://robinhoodchain.lighter.xyz/apikeys), [API Lighter Robinhood Chain](https://apidocs.rh.lighter.xyz/docs/get-started), [подключение Robinhood Wallet к dapps](https://robinhood.com/us/en/support/articles/connect-to-dapps/).


## Если Nado заменил signer

Nado допускает один linked signer на субаккаунт. Включение 1-Click Trading на сайте или новая привязка могут заменить ключ бота. Баланс продолжает читаться, но торговый ключ перестаёт действовать. При сообщении о несовпадении откройте **Торговля → Перепривязать ключ Nado**, выберите в MetaMask указанный адрес владельца и подтвердите подпись. Сохраняется тот же отдельный ключ бота; основной приватный ключ не требуется. Затем нажмите **Проверить доступ** и **Проверить без ордеров**. Включение другой привязки 1-Click Trading впоследствии снова может заменить signer бота.
