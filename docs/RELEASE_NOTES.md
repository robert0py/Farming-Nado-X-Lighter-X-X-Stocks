Windows x64 · Hedge Bot · тёмная панель Nado / Lighter Robinhood Chain.

- Интерфейс по референсу: боковое меню «Баланс» / «Торговля», две карточки аккаунтов, общая таблица активов и журнал фактических событий подключения.
- Никаких вымышленных балансов, сделок или истории. При запуске — «Не подключён» и прочерки.
- Для своих балансов: «Подключить» → адрес Nado и имя субаккаунта / адрес или индекс Lighter → «Показать баланс».
- Ключи и подпись кошелька не требуются. Это публичный просмотр, а не торговый вход.
- Балансы обновляются автоматически каждые 30 секунд и по кнопке «Обновить». Ошибка API очищает устаревшие суммы.
- Адреса, балансы и журнал событий не сохраняются на диск.
- Реальные сделки не поддерживаются. Серверный worker будет отдельным этапом.

Скачайте `Farming-Accounts.exe`; Python устанавливать не нужно. `SHA256SUMS.txt` содержит контрольную сумму сборки.
