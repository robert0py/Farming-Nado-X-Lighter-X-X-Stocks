Windows x64 · аккаунты и балансы Nado / Lighter Robinhood Chain.

- По умолчанию: деморежим, без запросов к площадкам.
- Для своих балансов: «Мои аккаунты · только чтение» → адрес Nado и имя субаккаунта → адрес или индекс Lighter.
- Ключи и подпись кошелька не требуются. Это публичный просмотр, а не торговый вход.
- Балансы обновляются вручную. Адреса и балансы не сохраняются на диск.
- Реальные сделки не поддерживаются. Серверный worker будет отдельным этапом.

Скачайте `Farming-Accounts.exe`; Python устанавливать не нужно. `SHA256SUMS.txt` содержит контрольную сумму сборки.
